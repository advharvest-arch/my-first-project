# Цепочка Селигер → Княжа → Серемо по исходным OSM

Исследование только исходных OSM-данных (node, порядок `nd`, way, relation, роли, общие узлы и рёбра).
Код проекта, база данных и WRG не изменялись.

Идентичность объекта и физическая связность ниже разделены. Из того, что вода стыкуется, не следует, что это один объект.

Визуализация участка: [seliger-knyazha-seremo.geojson](seliger-knyazha-seremo.geojson).

Источники: OSM API `relation/399081/full`, `relation/9617478/full`, `way/81753515/full`, `way/32487176/full`.

### Площадь или линия?

По структуре OSM, не по названию:

- way **замкнут**;
- стоит `natural=water` (в OSM это площадь);
- стоит `water=river` (тип водной площади: река, картированная полигоном);
- **нет** `waterway=river` на этом way.

**Вывод по модели OSM: way 81753515 — водная площадь (полигон), не линейный waterway.**

Линейный объект с тем же *именем* существует отдельно и имеет **другой** OSM id:

| | way 81753515 | way 32487176 |
|---|---|---|
| теги | `natural=water`, `water=river` | `waterway=river`, `name=Княжа` |
| замкнут | да | **нет** (17 узлов) |
| первый node | 952397004 (берег Селигера) | **952397092** (берег Серемо) |
| последний node | 952397004 | **220277673** (берег Селигера) |
| это | площадь | осевая линия |

Имя не делает их одним объектом: в OSM это два элемента. Ниже цепочка площади 81753515; линия 32487176 — отдельное наблюдение.

## 5. Главный вопрос

**Является ли Княжа отдельным водным объектом между Селигером и Серемо?**

По **идентичности OSM** — да, way 81753515 самостоятельный элемент:

- свой id;
- свои теги;
- не member ни 399081, ни 9617478;
- родительского relation нет.

По **геометрии** его полигон занимает пространство между двумя стыками: западное замыкание кольца делит берег с Селигером, восточный участок (idx 27–29) делит берег с Серемо.

OSM **не** содержит поля «это соединительный канал между озёрами A и B». Такой подписи нет. Есть только три объекта и два стыка по общим `node id`.

**Является ли Княжа частью Селигера, частью Серемо или самостоятельным объектом, физически соединяющим их?**

| Вопрос | Что говорит OSM |
|---|---|
| Часть Селигера? | **Нет** как член relation 399081. Совпадение только граничных узлов/рёбер. |
| Часть Серемо? | **Нет** как член relation 9617478. То же: общая граница, не членство. |
| Самостоятельный объект? | **Да** как отдельный way 81753515. |
| Физически соединяет их? | **Да** в смысле OSM-геометрии: площадь Княжи имеет общие node и рёбра с обоими, а Селигер и Серемо между собой общих node не имеют. |

Неоднозначность, которую OSM **не** снимает: являются ли эти три площади «одним водным телом» в гидрологическом или юридическом смысле. Членство relation этого не утверждает.

## 6. Идентичность ≠ физическая связность

**Идентичность (что считается отдельным объектом в OSM)**

- Селигер = relation **399081**
- Княжа (площадь) = way **81753515**
- Княжа (линия) = way **32487176** — ещё один id, то же имя не сливает их
- Серемо = relation **9617478**

Четыре идентификатора. Общая граница не меняет id и не включает way в чужой relation.

**Физическая связность (стык геометрий)**

- Селигер связан с площадью Княжи: 3 node + 2 ребра
- Площадь Княжи связана с Серемо: 3 node + 2 ребра
- Селигер с Серемо напрямую не связан: 0 node, 0 рёбер
- Линейная Княжа связана концевыми node с Серемо и с Селигером (общих рёбер с берегами нет)

Из связности **не** следует, что OSM считает их одним объектом.

## 7. Итог

```
ОБЪЕКТ A  Селигер     relation 399081
  │
  │ физическая связь
  │ way 49215822 ∩ way 81753515
  │ node 952397004, 220277673, 952396939
  │ рёбра ×2
  ↓
ОБЪЕКТ B  Княжа       way 81753515
  │
  │ физическая связь
  │ way 81753515 ∩ way 20542644
  │ node 749439906, 952397092, 220278932
  │ рёбра ×2
  ↓
ОБЪЕКТ C  Серемо      relation 9617478
```

### Что известно точно из OSM

- Три разных OSM-объекта (плюс отдельная осевая линия 32487176).
- Княжа-площадь замкнута, `natural=water` + `water=river` → площадь, не линейный waterway.
- Княжа-площадь не член Селигера и не член Серемо.
- Стыки — общие `node id` и общие рёбра на указанных ways.
- Прямого Селигер ↔ Серемо по node/рёбрам нет.

### Что можно вывести геометрически

- Полигон 81753515 лежит между двумя береговыми швами.
- На стыках соседние полигоны обходят общую границу в противоположных направлениях.
- Осевая 32487176 проходит от шва со Серемо до шва с Селигером внутри этой площади (её промежуточные узлы не лежат на кольцах озёр).

### Что OSM не позволяет установить

- Что это «одно озеро» или «система Селигера» как единый объект.
- Что Княжа «является частью» Селигера или Серемо.
- Навигационность, режим воды, ширину судового хода.
- Что имя `Княжа` что-либо доказывает (рядом есть другой объект `Княжка` 18072605 без общих узлов).
- Причину, почему маппер вынес перемычку отдельным way, а не включил её outer в одно из озёр.
