Нужен ключ Yandex Maps JS API v3

Этот прототип изолирован от AquaRoute/Leaflet. Ключ в репозиторий не коммитится.

Создайте sea-map/.env.local с строкой VITE_YANDEX_MAPS_API_KEY=ваш_ключ (или экспортируйте ту же переменную в окружение) и перезапустите npm run dev.

В кабинете разработчика Яндекса у ключа должен быть заполнен HTTP Referer (для local: http://localhost:*).
