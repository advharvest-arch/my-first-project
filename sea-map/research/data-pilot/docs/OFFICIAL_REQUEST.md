## Пилотный набор фолио (рекомендация)

Минимальный «позвоночник» Волга Рыбинск → НН (+ опционально до Казани):

| Код | Участок | Ячеек (каталог) |
| --- | --- | --- |
| **8R4001** | Рыбинское водохранилище | 8 |
| **8R5001** | Рыбинск → Ярославль | 4 |
| **8R5002** | Ярославль / Кострома → Заволжск | 6 |
| **8R4002** | Заволжск → Нижний Новгород | 5 |
| *опц.* **8R5003** | НН → Чебоксары | 9 |
| *опц.* **8R4003** | Чебоксары → Казань | 7 |

**Не брать сразу:** всю Волгу до Астрахани, всю Каму, всю Россию.

Отдельный микро-тест КиМ (если нужен канал/шлюзы отдельно): `8RKIM1` (+ при необходимости `8RKIM2`).  
Кама — только после успеха волжского пилота: `8RKAM1`….

Итого ячеек минимального пилота: **~23**; с Чебоксары/Казань: **~39**.

## Вопросы, которые ОБЯЗАТЕЛЬНО задать в лицензии

Лицензия на **просмотр ЭНК в ECDIS/ПО ≠** право на серверный routing.

Явно запросить письменный ответ:

1. Разрешён ли **server-side route calculation** по объектам ЭНК (не только отображение)?
2. Разрешено ли строить и хранить **производный routing graph / WaterGraph** (не копия ячеек S-63)?
3. Разрешено ли использование в **коммерческом B2C/B2B продукте** (AquaRoute)?
4. Можно ли хранить производный граф **на наших серверах** (РФ / иное)?
5. Нужен ли S-63 User Permit на сервер, или возможен **научный/тестовый S-57** без шифрования?
6. Периодичность и канал **корректур** (извещения, файлы обновлений)?
7. Можно ли получить **ограниченный тестовый комплект** (1–2 фолио) для R&D до полной коммерческой лицензии?

Уважаемые коллеги!

Просим рассмотреть возможность предоставления **пилотного комплекта** государственных ЭНК ВВП РФ (формат S-57 и/или S-63) по фолио:

- 8R4001, 8R5001, 8R5002, 8R4002  
  (опционально: 8R5003, 8R4003)

**Цель использования (не ECDIS-навигация судна):**  
исследовательская и продуктовая подготовка сервиса планирования маршрутов по ВВП (AquaRoute). Нам необходимо понять допустимость:

1. серверного расчёта маршрута с опорой на объекты ЭНК (RECTRC, FAIRWY, GATCON, DAMCON, OBSTRN, DEPARE и др.);
2. создания **производного** графа/слоёв (без редистрибуции исходных ячеек ЭНК конечным пользователям);
3. хранения производного графа на сервере правообладателя услуги;
4. коммерческого использования сервиса маршрутизации;
5. получения корректур в течение срока лицензии.

Просим сообщить: стоимость пилотного комплекта и годовой лицензии, срок поставки, формат (S-57 незашифрованный для R&D vs S-63), необходимые реквизиты/User Permit, и типовой лицензионный договор с ответами по пунктам выше.
