## 2. Можно ли использовать для серверного роутинга

**Неизвестно из публичных материалов — считать ЗАПРЕЩЁННЫМ до письменного разрешения.**

Публично ЭНК ВВП позиционируются как средство **отображения** (доп. к бумажным картам), поставка обычно **S-63** под User Permit ECDIS/ПО. Это **не** автоматически разрешает server-side route calculation.

В запросе обязателен явный пункт про server-side routing.

## 3. Можно ли строить производный WaterGraph

**Технически — да** (доказано синтетическим адаптером).  
**Юридически — только если лицензия явно разрешает derivative / derived data** и хранение на сервере; иначе нельзя класть производный граф в прод.

Адаптер: `research/data-pilot/` → `toWaterGraph()`.

## 10. Стоимость / лицензия / ограничения

| Вопрос | Публичный ответ |
| --- | --- |
| Цена фолио | **Не опубликована** фиксированным прайсом у ЦКТ/E-Data/Transas — только КП |
| Срок | Часто **~12 месяцев** + updates в периоде (Transas) |
| Формат | S-57/S-63; коммерция обычно S-63 |
| Просмотр ≠ routing | Критично: лицензия ECDIS **не** = серверный роутинг |
| Редистрибуция ячеек | Ожидаемо **запрещена**; возможен только derivative при согласии |
| Замена бумажных карт | Публично: ЭНК ВВП пока **доп. средство**, не замена |

Ориентир «от нескольких тыс. ₽ за комплект» встречается в вторичных обзорах для маломерных — **не опираться**; запросить КП на 4 фолио пилота.
