## Состав схемы

1. Компрессор сжатого воздуха  
2. Масловодоотделитель (фильтр)  
3. Редуктор давления с манометрами  
4. Лаконагнетательный бак с мешалкой и предохранительным клапаном  
5. Краскопульт (пневматический распылитель)  
6. Окрасочная кабина с поворотным столом и фильтром/завесой  
7. Вытяжной вентилятор  

Принцип: сжатый воздух давит на ЛКМ в баке и одновременно подаётся в сопло для распыления; окрасочный туман удаляется вытяжкой.

Открывается в AutoCAD, nanoCAD, КОМПАС (импорт DWG/DXF), LibreCAD (DXF).
